# 🍔 Reel-Style Food Delivery Web App (MERN Stack)

## 📌 Overview

A full-stack food delivery web application built with the MERN stack, featuring a reel-style scrolling interface for mobile users. The platform includes both a user-facing app and an admin panel for managing food items, orders, and basic operations.

---

## 🚀 Features

### 👤 User Side

* 📱 **Mobile-First Design** – Optimized for mobile devices
* 🎞️ **Reel-Style Browsing** – Vertical scroll to explore food items
* 🛒 **Order Placement** – Select and place orders 
* 🔐 **Fake Payment System** – OTP-based demo payment (fixed OTP required)

### 🛠️ Admin Panel

* 📦 **Manage Food Items** – Add, edit, delete products


---

## 🛠️ Tech Stack

* **Frontend:** React.js, Tailwind CSS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB


---

## 💳 Payment Simulation

* Uses a **mock OTP verification system**
* Orders are placed only after entering the correct OTP
* No real payment gateway integration

---

## 📱 Responsiveness

* Designed primarily for **mobile devices**
* Limited support for larger screens

---

## 📂 Project Purpose

This project demonstrates:

* Full-stack development using MERN
* Admin panel architecture
* API integration and CRUD operations
* Creative UI/UX with reel-style interaction

---

## ⚠️ Disclaimer

* This is a **demo project**
